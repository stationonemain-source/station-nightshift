Six areas, sixty-nine checks.

Everything below runs automatically against the systems you own, and only with your written permission.

Email spoofing

  • SPF record present, correct and not too loose
  • DMARC present and actually enforced
  • DKIM signing in place
  • Mail servers checked against spam blocklists
  • Catches the gap behind invoice fraud and gift-card scams

Network exposure

  • Remote Desktop (RDP) open to the internet
  • Windows file sharing (SMB) exposed
  • Databases reachable from outside
  • Telnet, FTP, VNC, exposed printers and cameras
  • Remote admin panels and an oversized attack surface

Website

  • Served over HTTPS, with proper redirects
  • Security headers and secure cookies
  • Exposed .git, .env, backups, config and log files
  • Open admin panels and directory listings
  • Outdated WordPress, user leaks, known plugin flaws

Encryption

  • Certificate expired or expiring soon
  • Certificate matches the site name and is trusted
  • Outdated TLS versions still allowed
  • Weak ciphers and weak keys
  • Flags the problems that fail payment-card (PCI) rules

DNS & domain

  • Forgotten subdomains that can be hijacked
  • DNS servers that leak the whole network map
  • Domain registration about to expire (a full outage risk)
  • Registrar transfer lock and DNSSEC

Reputation & exposure

  • Domain or server on a malware or phishing blocklist
  • Staff emails showing up in known data breaches
  • Known vulnerabilities (CVEs) in the software you run
  • Default or factory passwords still accepted

Each finding becomes one plain-English item in your report: what it is, why it matters to your business, and exactly how to fix it. One critical issue, like an exposed database, caps the overall grade, so the score can never look reassuring while something serious is open.
